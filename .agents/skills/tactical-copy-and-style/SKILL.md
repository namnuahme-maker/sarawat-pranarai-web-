# Tactical Copy & Style Guide (SARAWAT PRANARAI)

คู่มือและมาตรฐานการจัดการภาษา ข้อความ และการตกแต่ง UI/UX ประจำระบบปฏิบัติการสารวัตรนักเรียน โรงเรียนพระนารายณ์

---

## 1. Tone of Voice & Copywriting (หลักการใช้ภาษาและน้ำเสียง)

### 1.1 บุคลิกของระบบ (Personality)
- **เคร่งครัด วินัย แม่นยำ (Disciplined & Tactical):** กระชับ ตรงประเด็น ไม่มีพิธีรีตอง ไม่ใช้คำสร้อยเยิ่นเย้อ
- **สุภาพและให้เกียรติ (Respectful):** ใช้สรรพนามเรียกสมาชิกว่า `คุณ...` หรือตามด้วยยศ/รหัสเวร เช่น `[TS1] คุณธนกร`
- **เป็นทางการและเชื่อถือได้ (Institutional):** สะท้อนความเป็นงานวินัยและกิจการนักเรียนโรงเรียนพระนารายณ์

### 1.2 กฎเหล็กด้านภาษา (Copy Rules)
- **ห้ามใส่ Emoji พร่ำเพรื่อ (Anti-Emoji Clutter):**
  - ห้ามใช้อีโมจิซ้อนกันในหัวข้อ เช่น `📋 [รายงานสถานะ...]` หรือ `📅 17`
  - อนุญาตให้ใช้อีโมจิได้ไม่เกิน 1 ตัวต่อบล็อก เพื่อใช้เป็น visual indicator เท่านั้น (เช่น `•`, `✓`, `🚨`)
- **ห้ามใช้คำทับศัพท์ที่ไม่จำเป็น:**
  - ใช้ `ผลัดเวร` แทน `Shift` ในข้อความภาษาไทย
  - ใช้ `วัตถุพยาน / สิ่งของสูญหาย` แทนคำกำกวม
  - ใช้ `ส่งมอบคืน` แทน `Handover`
- **ข้อความปุ่ม (Button Microcopy):**
  - ต้องขึ้นต้นด้วยกริยา + กรรม ที่ชัดเจน เช่น:
    - `🟢 ลงเวลาเข้าเวร` (ดี) vs `กดที่นี่` (ห้ามใช้)
    - `✓ บันทึกส่งมอบคืน` (ดี) vs `ตกลง` (ห้ามใช้)
    - `🔍 ขอตรวจพื้นที่ด่วน` (ดี) vs `ออกตรวจ` (ห้ามใช้)

## 2. Discord Embed & Messaging Standards (การตกแต่งการ์ด Discord)

### 2.1 โครงสร้างการ์ด Embed มาตรฐาน
```text
[ชื่อหัวข้อกระชับ ไม่มี Bracket]

# เวร[ชื่อวัน] ([รหัสผลัด])
• ประจำวันที่: [วัน เดือน ปี ภาษาไทย]
• อัปเดตล่าสุด: <t:[timestamp]:R>

━━━━━━━━━━━━━━━━━━━━━━━━━━━━
### สรุปความพร้อมกำลังพล
• กำลังพลตามตารางทั้งหมด: X นาย
• ขอยอดลาเวร: Y นาย
• พร้อมปฏิบัติหน้าที่จริง: Z นาย (XX%)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━

### รายชื่อสารวัตรที่ขอลาเวร (Y นาย):
1. [รหัสเวร] คุณ[ชื่อเล่น] ([ชั้น/ห้อง])
   └ [ประเภทการลา] ([ช่วงเวลา]) • [เหตุผล] | คนแทน: [ชื่อคนแทน]

━━━━━━━━━━━━━━━━━━━━━━━━━━━━
### สารวัตรที่พร้อมปฏิบัติหน้าที่ (Z นาย):
• `[รหัสเวร]` คุณ[ชื่อเล่น]
• `[รหัสเวร]` คุณ[ชื่อเล่น]
```

### 2.2 กฎการแสดงผลรายชื่อ (Mandatory List-Down Rule)
- **ห้ามเรียงชื่อแนวนอนยาวเด็ดขาด** (เช่น `[T1] แสน [TS3] แบงก์ ...` ห้ามใช้)
- **ต้องจัดเรียงลงมาทีละบรรทัด (Vertical List Down)** พร้อม Bullet Point `•` และรหัสเวรใน Code block เสมอ เพื่อให้อ่านง่ายบนจอมือถือ

### 2.3 รหัสสีของเส้นขอบ Embed (Accent Strip Colors)
- 🟢 **Emerald Green (`#2ECC71`):** สภาพปกติ กำลังพลพร้อม 100%, ปฏิบัติหน้าที่สำเร็จ
- 🟠 **Amber Orange (`#F39C12`):** มีการลาเวร, รอยืนยันจุดสังเกตลับ, รออนุมัติ
- 🔴 **Crimson Red (`#E74C3C`):** สัญญาณเหตุด่วน (Tactical Dispatch), ขาดเวร, ล้างระบบ (KillFile)
- 🔵 **Tactical Blue (`#3498DB` / `#5865F2`):** การแจ้งเตือนเวรประจำวัน, ข้อมูลบริการทั่วไป

## 3. Web UI Styling & Polish Standards (การตกแต่งหน้าเว็บ)

### 3.1 ธีมสีประจำสถานี (Tactical Station Palette)
- **Canvas / Background:** Dark Slate Navy (`#0B0F19` และ `#0F172A`)
- **Card Background:** Elevated Slate (`#131B2E` และ `#1E293B`)
- **Card Borders:** Subtle Border (`#1E293B` หรือ `#334155`) ความหนา 1px
- **Primary Accent:** Tactical Sky Blue (`#38BDF8` หรือ `#2563EB`)
- **Success Accent:** Emerald Green (`#10B981` หรือ `#059669`)
- **Danger Accent:** Tactical Red (`#EF4444` หรือ `#DC2626`)
- **Text Color:** Pure White (`#F8FAFC`) สำหรับหัวข้อ และ Muted Slate (`#94A3B8`) สำหรับข้อความรอง

### 3.2 กฎห้ามทำใน UI (Anti-Slop Rules)
- ห้ามใช้แสงสีม่วง-ชมพูฟุ้ง หรือเงา Blur หลากสีแบบ AI เจนเนอเรต
- ห้ามแต่งตัวเลขสถิติปลอม หรือรีวิวประดิษฐ์ขึ้นเอง
- รักษาระดับ Contrast ตามมาตรฐาน WCAG AA (อย่างน้อย 4.5:1) เสมอ เพื่อให้อ่านได้ชัดเจนในสภาพแสงกลางแจ้งขณะออกตรวจเวร
