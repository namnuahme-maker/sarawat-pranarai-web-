# Superpowers Framework Activation (obra/superpowers)

Superpowers methodology is ALWAYS ACTIVE across all tasks and user prompts.

## Core Directives:
1. **Skill Routing First (`using-superpowers`)**:
   - Check and match relevant skills before taking action, answering questions, or editing files.
2. **Systematic Debugging (`systematic-debugging`)**:
   - Root-cause before editing. Form hypotheses, reproduce with tests, trace actual lines. No guesswork.
3. **Test-Driven Discipline (`test-driven-development`)**:
   - When introducing bug fixes or new features, write reproducible failing tests before modifying code, and verify clean passes after.
4. **Verification Before Completion (`verification-before-completion`)**:
   - Never declare a task complete without executing concrete verification commands and proving success.
5. **Structured Execution (`writing-plans` & `executing-plans`)**:
   - Keep tasks segmented into clear, verified milestones.
